5G QoS

Understand the relationship between QoS flows, 5QI and radio bearers.

Why QoS matters

5G can treat different application traffic differently. QoS flows provide the logical QoS granularity, while radio bearers carry the traffic over the radio interface.

TermSimple meaning
5QIA standardized QoS identifier used to characterize QoS treatment.
QoS FlowA logical unit of traffic with a defined QoS profile.
DRBData Radio Bearer used to carry user-plane traffic over NR.

Validation idea

When testing a QoS requirement, validate the complete chain: application traffic → core QoS policy → QoS flow → radio configuration → measured behaviour.

QoS in simple terms

QoS is about giving different traffic the treatment it needs. In 5G, the QoS flow is the logical unit used to apply QoS treatment. The network can map that flow toward radio resources and a data path that supports the required service behaviour.

5QI and QoS flow

5QI is an identifier associated with a defined QoS treatment. A QoS flow groups traffic that should receive the same QoS handling. The practical question is not just which 5QI is configured, but whether the expected QoS behaviour is visible across the complete path.

From policy to radio

For validation, connect application traffic, core policy, QoS flow, radio bearer and measured performance. If one part of that chain is wrong, the final throughput or latency result may be misleading.
