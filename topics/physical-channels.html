5G NR Physical Channels

A simple guide to PDSCH, PUSCH, PDCCH and PUCCH.

Control vs user data

A useful first distinction is between channels that mainly carry user data and channels that carry control information.

ChannelDirectionSimple role
PDSCHDownlinkDownlink shared channel for user data and some higher-layer information.
PUSCHUplinkUplink shared channel for UE data and configured/control information.
PDCCHDownlinkCarries downlink control information used for scheduling and control.
PUCCHUplinkUplink control information such as HARQ feedback and scheduling-related information.

Debugging approach

Do not treat a missing data packet as automatically a PHY problem. Check whether control signalling successfully scheduled the transmission, whether the UE was configured correctly and whether higher layers requested data.

Reference: TS 38.211 is the main 3GPP specification for NR physical channels and modulation; TS 38.213 and TS 38.214 cover important physical-layer control and data procedures.

Start with four channels

PDSCH and PUSCH are the main shared channels for downlink and uplink data. PDCCH carries scheduling and other downlink control information, while PUCCH carries uplink control information such as feedback. A simple first question is therefore: am I looking at data or control?

How scheduling fits in

The UE normally does not transmit or receive arbitrary data whenever it wants. The network schedules radio resources. Control information tells the UE when and where relevant resources are available, while the shared channels carry the resulting data.

What to check in a failure

If a data transmission is missing, check the control side first. Look for scheduling, configuration, timing and the expected channel before concluding that the problem is a physical-layer failure. This is especially useful when correlating protocol logs with modem traces.
