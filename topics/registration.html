5G Registration

Follow the basic UE registration journey from radio access to the 5G Core.

What is registration?

Registration is the process by which the UE establishes the required access and mobility relationship with the 5G Core. In a real trace, the radio procedure and NAS procedure are closely connected.

A simplified journey

  1. UE discovers and selects a suitable cell.
  2. UE establishes the required radio signalling.
  3. NAS registration signalling is exchanged toward the core.
  4. Authentication and security procedures occur as required.
  5. The UE reaches a registered state if the procedure succeeds.

When it fails

Look for the first failure rather than the final symptom. Check cell selection, RRC establishment, NAS messages, reject causes, timers, security and network configuration.

Log-analysis tip: create one timeline with RRC and NAS events instead of examining each protocol independently.
