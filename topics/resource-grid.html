5G NR Resource Grid

See how time and frequency resources are organized in NR.

What is the resource grid?

The resource grid is the time-frequency map used to describe NR transmissions. 3GPP defines a resource grid for a given numerology, carrier and transmission direction such as downlink or uplink.

TermSimple meaning
Resource element (RE)One subcarrier in one OFDM symbol.
Resource blockA group of subcarriers used as a basic scheduling resource.
OFDM symbolA time-domain unit in the grid.
SlotA collection of symbols used for scheduling and transmission timing.

Why this is useful in log analysis

If a trace shows a bandwidth, SCS, BWP or allocation change, the resource-grid view helps translate configuration into what the radio is actually scheduling.

Practical habit: whenever you see a resource allocation problem, record carrier bandwidth, SCS, BWP, slot timing and the physical channel involved before looking for the root cause.

How to picture it

Imagine a grid with frequency on one axis and time on the other. The smallest useful unit is a resource element. Groups of resource elements form larger scheduling structures, and NR uses these structures to place control, reference signals and data.

Why PRBs are important

A physical resource block is a practical scheduling unit. When a UE is assigned PRBs, the scheduler is deciding where the transmission will occupy the time-frequency grid. This is why PRB allocation is useful evidence when investigating throughput, scheduling or radio-resource problems.

From theory to logs

A good investigation connects the configuration to the observed allocation: carrier and BWP → SCS → slot timing → PRB allocation → physical channel → measured result. This gives you a repeatable way to move from a log entry to a radio explanation.
