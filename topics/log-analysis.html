UE & protocol log analysis

A working section for future real-world troubleshooting notes, trace examples and lessons learned.

How I approach a log

  1. Start with the symptom and the exact time it happened.
  2. Build the timeline around the failure.
  3. Identify the first abnormal message or measurement.
  4. Correlate UE, RAN and core events where available.
  5. Separate the trigger from the later symptoms.
  6. Use the relevant 3GPP procedure to confirm expected behaviour.
