5G NR Architecture

How UE, gNB, NG-RAN and the 5G Core fit together.

The big picture

In a simple view, a 5G system has the UE, the NG-RAN and the 5G Core. The gNB provides NR radio access. NG-RAN connects toward the 5G Core over NG interfaces, while NG-RAN nodes can also communicate over Xn.

PartSimple meaning
UEThe phone, modem or device using the network.
gNBThe 5G radio access node that terminates NR control/user-plane protocols toward the UE.
AMFCore function responsible for access and mobility management.
SMFCore function responsible for session management.
UPFUser-plane function that forwards user traffic.

How to think during troubleshooting

When a test fails, first decide whether the evidence points to radio access, signalling, session management or user-plane forwarding. This prevents jumping between layers without a timeline.

3GPP reference: TS 38.300 describes NR and NG-RAN overall architecture and procedures. The current 3GPP specification list also includes dedicated specifications for RRC, MAC, RLC and PDCP.
