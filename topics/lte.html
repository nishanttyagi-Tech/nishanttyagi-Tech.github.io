LTE Architecture

4G RAN, EPC, protocol stack and important procedures.

System view

LTE separates the radio access network from the evolved packet core. Understanding the interfaces helps explain where signaling and user traffic travel.

Protocol stack

Important radio-side layers include PHY, MAC, RLC, PDCP and RRC. Each layer has a defined responsibility and interacts with neighboring layers.
