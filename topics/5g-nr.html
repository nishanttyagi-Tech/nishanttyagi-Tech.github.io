5G NR

5G NR Fundamentals

A structured starting point for understanding 5G New Radio — from the system view down to the resource grid and physical channels.

1. Start with the system

5G NR is the radio access technology used by 5G networks. A useful learning sequence is architecture → numerology → resource grid → channels → signaling procedures.

Study principle: connect every physical-layer concept to the higher-layer procedure where it is actually used.

2. Resource grid

NR organizes radio resources in frequency and time. A physical resource block contains 12 consecutive subcarriers. Numerology controls subcarrier spacing and therefore the time structure.
