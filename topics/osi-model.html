Networking

OSI Model

The OSI model provides a useful conceptual way to reason about network communication.

The seven layers

  1. Physical
  2. Data Link
  3. Network
  4. Transport
  5. Session
  6. Presentation
  7. Application

Practical view

Use the model as a troubleshooting map rather than memorizing the layers in isolation. Ask which layer owns the behavior you are observing.
