SIP fundamentals and call flows

SIP is a signalling protocol used to establish, modify and terminate communication sessions. In telecom, it is especially important when understanding IMS and packet voice.

What is SIP?

SIP messages create and manage sessions. The signalling is separate from the media itself, which is commonly described through SDP information carried within SIP messages.

REGISTER

A REGISTER transaction is used by a user agent to register its contact information with the relevant SIP/IMS infrastructure.

INVITE

INVITE begins a session establishment attempt. The following responses and acknowledgements build the call flow and show whether the session is progressing correctly.

Responses

Responses use status classes such as provisional, successful and error responses. Reading the sequence is often more useful than looking at one message in isolation.

Simple call flow

  1. REGISTER and authentication.
  2. INVITE with session information.
  3. Provisional response while the session is being processed.
  4. Successful response with negotiated session details.
  5. ACK confirms establishment.
  6. BYE terminates the session.

SIP and IMS

IMS uses SIP as a key signalling mechanism for multimedia services. For troubleshooting, correlate SIP messages with UE logs, IP traces and radio/core events rather than analysing SIP in isolation.
