5G NR RRC

Understand the control layer that configures and manages the UE radio connection.

What is RRC?

RRC means Radio Resource Control. It is the key NR control-plane protocol between the UE and the NG-RAN for radio configuration, connection management and many mobility procedures.

Useful states

StateSimple view
RRC_IDLEThe UE is not in an active RRC connection with the cell.
RRC_INACTIVEThe UE can retain context while reducing signalling and radio activity.
RRC_CONNECTEDThe UE has an active RRC connection and can be configured for active services.

Messages worth recognizing

When reading traces, become comfortable with RRCSetup, RRCSetupComplete, RRCReconfiguration, RRCReconfigurationComplete, measurement-related messages and release/re-establishment procedures.

Reference: 3GPP TS 38.331 is the NR RRC protocol specification and is under change control.

What RRC actually does

RRC is the radio-control layer between the UE and NG-RAN. It helps establish, maintain, configure and release the radio connection. It also carries important configuration for measurements, mobility and radio bearers.

Why the states matter

RRC_IDLE, RRC_INACTIVE and RRC_CONNECTED describe different levels of radio connection and retained context. The important engineering point is that the UE does not behave the same way in every state, so a trace should always be interpreted in the context of the current RRC state.

How to read an RRC trace

Start with the first message that changes the procedure, then follow the response. For example, RRCSetup and RRCSetupComplete establish the connection, while RRCReconfiguration can change radio configuration. Timing, cause values and message sequence are often more useful than reading one message alone.
